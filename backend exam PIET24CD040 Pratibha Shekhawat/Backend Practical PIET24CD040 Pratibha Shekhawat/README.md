## Projects Included

### A1 – Library Book Management API
A RESTful API developed using Node.js, Express.js and MongoDB.

**Features:**
- Add a new book
- View all books
- View a book by ID
- Update book details
- Delete a book
- Input validation and error handling

### A2 – Student Portal with Authentication
A backend application implementing user authentication and protected routes.

**Features:**
- User registration
- User login
- Password hashing
- JWT-based authentication
- Protected profile route
- Admin-only student listing
- Security middleware

## Technologies Used
